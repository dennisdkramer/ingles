## Open bugs / problems
- B-F12 [2026-10-25, owner request] REVERT BUTTON DISABLED OUTSIDE EDIT MODE: the control-bar "↩️ Revert" button is currently always clickable. It must be greyed/disabled while the normal (non-edit) page is displayed, and become clickable only during edit mode (there is nothing to revert until edits exist).
- B-F8 [2026-10-14, owner report] RECORDING ON A STRING THAT TOUCHES A NOTE DROPS THE NOTE FROM THE POPUP: after ⏺ Record saves, `rec()` refreshes the popup (`refreshNbPopup`), which rebuilds it keyed to the recording's anchor and the note the selection was about disappears. The popup must keep showing that note after a recording saves.
- B-F7 [2026-10-14, owner report] ONE NOTE HAS AN UNCLICKABLE 📝 DELETE: selecting that note leaves the 📝 Delete button disabled (`nbPopState` finds no note for it), yet Clear page deletes it. Reproduce with a real selection to see which note and why its anchor isn't resolving.
- B-F6 [2026-10-14, owner report] RAPID ACTIONS FAIL SERVER SAVES/DELETES: rapid subsequent actions cause failed writes, highlights that appear and re-appear, and overlapping highlights that should be impossible. The 12s grace window only DELAYS the drop (a write the server never received is erased once the window expires). Cause: concurrent POSTs (a highlight-subtract gesture emits 2–3) with no client-side queue, retry or local retention — see the outbox/retry plan.
- B-F5 [2026-10-14, owner report] BOLD AND UNDERLINED TEXT CHANGES A HIGHLIGHT'S COLOUR STRENGTH: the highlight rectangle is `mix-blend-mode:multiply`, so the tint reads differently over bold glyphs and over a recording's blue underline.
- B-I11 [2026-10-25, owner report] SELECTION GESTURE FIRES ON NON-CONTENT (bug + rule): selecting text in some page fields triggers the note/record popup, while others throw an error. Rule: text fields (inputs), buttons (with ONE exception — radio button label text stays selectable), the page header and the control bar must be COMPLETELY excluded from highlight/note/record — no interaction, no popup, no error toast.
