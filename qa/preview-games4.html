Games v2 — preview

Not a lesson. Open this file and judge the look and feel. Each game block now opens on its own intro screen — the how-text, the stats (rounds · seconds each · keys) and a Play button — and the authored radios behind it stay hidden while the engine is alive. Swapping data-game changes the game without touching the content; data-time is the per-item deadline in milliseconds.
