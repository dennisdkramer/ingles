# PRONUNCIATION KEY — durable reference

## L1 parsing principle
Judge every syllable break by: does it teach the correct RHYTHM to a Brazilian beginner?
- Keep consonant clusters whole as onsets ("mash" them).
- Split at true word/compound boundaries.
- "Both ways" → pick the rhythm-teaching break.
No exhaustive consonant list — intuition drives L1; these examples are calibration only:
- tr: rat-race (split) · re-try (whole) · re-tro-fit (over ret-ro-fit)
- sf: mi-sfit (mash)
- st: mis-treat (split) · a-stray (whole)
- nd: in-deed

## Level 2 — phonetic respelling (Brazilian clarity), generated by intuition
Character conventions (proposals to confirm):
- ə = schwa
- augh → af (laugh) / au (caught) — by sound
- sh → x (Portuguese x = /ʃ/)
- ch → tch (Portuguese tch = /tʃ/)
- j → dj (Portuguese dj = /dʒ/)
- th → t (voiceless) / d (voiced)
- vowels reuse: ei ai i e a o u ô ó â

Examples: laughable → *la-fə-bl[e] · ship → xip · chair → tcher · think → tink · this → dis
