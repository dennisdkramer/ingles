# Lesson 23 — design (Pass A)

`recycles:` lesson 18 (the machinery; *set up, put off, sort out, look into, break down, get over* already owned),
lesson 22 (*turn into*, the formal-twin habit), lesson 17 (*by* deadlines, *until*), lesson 20 (the perfect for
"already done"), lesson 15 (obligation: *we have to wrap this up*).
`must not re-teach:` what a phrasal verb is, particle meanings, the pronoun rule (lesson 18); the people/talk set
(lesson 22); the passive (lesson 29); the articles (lesson 24).

## Core (what the student can do afterwards)
1. **Run a project in phrasal verbs**: set up (arrange), wrap up (finish), carry out (perform), take over (assume
   control), hand in (submit), sign off (approve).
2. **Say what got stuck and how it moved**: figure out / work out (solve, understand), keep up with (stay level),
   break down (fail, or analyse), get over (recover — recycled), look into (investigate — recycled).
3. **Separate only where the sentence decides**: *carry it out*, *hand it in*, *sign it off* (pronoun inside);
   *look into it*, *keep up with it* (inseparable) — the rule of 18 applied to a new set.
4. **Switch to the minutes**: arrange, postpone, perform, submit, approve, resolve, investigate.
5. Tell a retrospective story: what we set up, what broke down, what we figured out, what we handed in.

## Teaching beats and dependencies
- **The project has a life cycle, and the verbs mark the stages**: set up → carry out → wrap up → hand in → sign
  off. Teaching them in order is what makes them memorable; a list would not.
- **Bad news has its own verbs**: break down, fall behind (kept to *keep up with* as its positive), get over.
  The lesson pairs each bad-news verb with the sentence a manager actually says.
- **`break down` is two verbs**: a machine fails; a manager analyses. Same form, different object — the context
  decides, and the note says so.
- **`figure out` and `work out` are interchangeable** in this register; *work out* also means exercise, which the
  note flags so the student does not meet it by surprise.
- **Separability drill uses only the new verbs**, so the student applies 18's rule instead of reciting it.
- **Dependencies**: the deadlines come from 17; the obligation frames from 15; the formal twins continue 22.

## Situation
A project retrospective: the kickoff, the week everything broke, the fix, the delivery, the sign-off. The student
is the one who has to explain the sequence to a manager who was not there.

## Candidates (three channels)
- **Read — the retrospective note.** Six lines, one per stage; the student orders them and matches each to its
  formal twin.
- **Done — the pronoun drill + the stage builder.** New verbs only, twice: noun object and pronoun object.
- **Heard — the status call.** Four lines where *break down*, *keep up with*, *take over* and *sign off* decide the
  meaning; the student ticks what happened.

## Chosen
**Read → Done → Heard.** The retrospective first because the life cycle is the mnemonic; then the mechanical drill;
then the call, because these verbs are heard in bad-news conversations far more than they are read.

**First 30 seconds:** *The printer broke down again.* — the student clicks whether the printer stopped working or
was analysed. Nothing is defined.

## What the student produces (evidence)
Six stage verbs from formal twins, four pronoun placements, four bad-news meanings, four listening items, a spoken
retrospective of six sentences, a written status line for the minutes, then a no-consultation quiz with no reused
item.
