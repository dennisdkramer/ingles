# Lesson 31 — design (Pass A)

`recycles:` lesson 6-7 (past simple of habits), lesson 11 (past continuous for scene-setting), lesson 4 (routine and
frequency), lesson 28 (verb + -ing — *be used to* takes the -ing form), lesson 14 (reductions — *used to* is
pronounced /juːstə/).
`must not re-teach:` the past simple itself; frequency adverbs (8); the -ing vs to system (28) — only the
*be used to + -ing* slot is new.

## Core (what the student can do afterwards)
1. **Past habit**: *used to + base* — *I used to work nights*; and past state: *there used to be a shop here*.
2. **Question and negative correctly**: *didn't use to*, *did you use to…?* (no *d*).
3. **Repeated actions with *would*** — and never with states.
4. **Familiarity now**: *be used to + -ing/noun* (*I'm used to presenting in English*), *get used to* for the
   process of adapting.
5. **Keep the three look-alikes apart**: *used to work / be used to working / use a tool for*.

## Teaching beats and dependencies
- **Two different ideas share a shape**: *used to* is about the **past**; *be used to* is about the **present
  familiarity**. The lesson separates them by time, not by translation.
- **`would` only repeats actions, never states**: *we would meet every Friday* (habit) but not *there would be a
  shop* — for states, only *used to*.
- **The negative is *didn't use to*** — the *d* belongs to the past tense, and *did* already carries it.
- **The pronunciation collapses**: *used to* = /juːstə/ — the same reduction logic as lesson 14.
- **`be used to` takes a noun or -ing**, because *to* here is a **preposition**, not an infinitive marker. That is
  the whole confusion, and naming it solves it.
- **Dependencies**: the -ing form (4/28); the past simple (6); the reductions (14).

## Situation
A change programme: the team moved office and software in the same quarter. The old-timers describe how things used
to be, the new joiners describe what they are still getting used to, and one manager confuses the two in front of
everyone.

## Candidates (three channels)
- **Read — the change note.** Eight sentences comparing before and now; the student chooses *used to / be used to*
  and marks the states.
- **Done — the pair drill.** *used to* vs *be used to* in the same sentence frame, so the time is the only variable.
- **Heard — the corridor.** Four lines with *used to* at speed (/juːstə/); the student writes the full form.

## Chosen
**Read → Done → Heard.** The change note first because the contrast *before/now* is the lesson's spine; then the
pair drill, which forces the time decision; then the ear, because /juːstə/ hides the *d* and the student needs to
recognise it.

**First 30 seconds:** *I used to work in the old office.* — the student clicks whether the person works there now.
Nothing is defined.

## What the student produces (evidence)
Six before/now choices, four negatives/questions, four *would* vs *used to* decisions, four *be/get used to*
completions, four listening items, a spoken comparison of the old and new office, then a no-consultation quiz with
no reused item.

## Width note (for Pass B)
The before/now chart and the look-alike chart are full width (five fields per row). The negative/question group and
the familiarity group sit as halves in one row — two four-item groups that would each leave a full slot more than
half empty.
