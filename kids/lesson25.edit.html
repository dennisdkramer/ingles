Unless, as long as, in case — the other words for if

O que esta aula instala: a hipótese não é assunto de prova — é ferramenta de negociação. Dizer "If we could take turns, would that work?" consegue o jogo emprestado sem briga, porque não afirma nada: ninguém precisa se defender. E cada substituto de if carrega uma lógica diferente — unless (a única exceção), as long as (a condição que precisa valer), in case (preparação, não condição), otherwise (o resultado de não fazer), even if (o resultado não muda).

2. A emenda — duas metades, dois tempos

Uma frase hipotética não é uma forma só: são duas metades costuradas. Cada metade guarda o seu tempo — e é exatamente isso que a pessoa quer dizer.

Metade 1 (a condição)Metade 2 (o resultado)O que a frase diz
If I had a bike (agora)I would have gone (então)não tenho → não fui
If I had studied (então)I would be calmer (agora)não estudei → estou nervoso
If it weren't raining (agora)we would have played (então)está chovendo → não jogamos
Não é uma quinta forma. As quatro formas são da aula 19 e continuam iguais; aqui só se costura uma metade de cada. Se as duas metades forem do mesmo tempo, a frase é a de sempre.

3. unless — a única exceção

Com ifCom unlessSentido
I'll go if it doesn't rain.I'll go unless it rains.só a chuva impede
She'll come if she isn't tired.She'll come unless she's tired.só o cansaço impede
We'll play if it isn't dark.We'll play unless it gets dark.só a escuridão impede
O erro: "unless it doesn't rain". O not já está dentro de unless — unless = if…not. Use um ou outro, nunca os dois.

4. as long as — a condição que precisa valer

FraseA condição que precisa valer
You can play as long as you finish your homework.terminar a lição
We'll be there as long as my mum says yes.a autorização
It's fine as long as we don't break it.não quebrar
provided faz o mesmo e é mais formal — You may borrow it provided you return it. É a versão de bilhete para os pais.

5. in case — preparação, não condição

FraseO que ela realmente dizO que NÃO diz
Take an umbrella in case it rains.leve antes, por precauçãonão é "se chover, leve"
I'll bring money in case we need some.trago por precauçãonão é uma condição de ir
Keep it in your bag in case you forget it.guarde agora, por garantiaa ordem não depende do esquecimento
A armadilha do português. "Caso chova, leve o guarda-chuva" tem ação depois; in case tem ação antes. Traduzir palavra por palavra erra a ordem das coisas. Se for condição mesmo, use if.
