If… — four boxes, one law

O que esta aula instala: escolher pelo distanciamento, não pelo tempo. Zero = sempre verdade. 1º = real e futuro. 2º = irreal agora. 3º = irreal antes. Uma lei só: a oração do if volta um passo; o resultado pega o operador. E o erro que morre hoje: "if it will rain" — depois de if o futuro nunca aparece.

Em uma frase: a oração do if dá o passo, o resultado paga a conta. Nunca os dois do mesmo jeito.

4. O passado é distância

If I had a bike, I would ride to school. — a bicicleta não existe hoje. O passado (had) não fala de ontem: fala de longe da realidade.

FraseTempo de verdadeRealidade
If I have time, I'll go.futuropode acontecer
If I had time, I would go.agoranão tenho tempo
If I had had time, I would have gone.passadonão tive tempo
Mesma ideia, três distâncias. Só muda o quanto ela está longe — e o had do 2º é distância, não passado.
