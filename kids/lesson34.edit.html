Dear Ms Lima — the same message, three readers

O que esta aula instala: tom não é humor — é um conjunto de interruptores: saudação, contração, franqueza, imperativo, despedida. Cada um tem três posições, e o que decide é o leitor, não a personalidade de quem escreve. A armadilha tem nome: o imperativo. Send the form é neutro dentro do grupo e rude para a secretaria — e uma palavra conserta.

Subir de nível não é escrever mais. É trocar três ou quatro peças — o resto da mensagem fica igual.

4. O imperativo — a armadilha de uma palavra

Uma palavra — could — transforma ordem em pedido. Não é enfeite: é a diferença entre os dois leitores.

5. Ler o leitor

Ler o leitor é decidir o que mudar, não mudar tudo. A mesma frase pode viajar; a saudação, o pedido e a despedida é que trocam.

6. Os quatro recados difíceis

TipoFormaExemploErro comum

Má notícia nunca sozinha. As três peças, sempre nesta ordem: reconhecer, a notícia, o que ainda se pode fazer.
