I used to walk — the habit that ended

O que esta aula instala: duas ideias diferentes usam uma forma parecida. used to fala do passado — um hábito que não existe mais. be used to fala de agora — o que já é familiar. A aula separa as duas pelo tempo, nunca pela tradução. E há um detalhe que resolve a confusão toda: em be used to, o to é preposição, então o que vem depois é substantivo ou -ing.

2. used to — o hábito que terminou

Antes (used to)AgoraO que mudou
I used to walk to school.I go by bus.o hábito acabou
We used to play in that park.It's a car park now.o lugar mudou
There used to be a big tree here.There's a bench here.não é ação: é estado
Só passado. Used to nunca descreve o presente — se ainda acontece, usa-se o presente simples sem used to.

3. Negativa e pergunta

FraseCerto?Por quê
I didn't use to like fish.✔o did já carrega o passado, então o verbo volta a use
"I didn't used to like fish."✘o d é do passado e já está no didn't
Did you use to live here?✔mesma regra na pergunta
I never used to eat at school.✔afirmativa com never: o d fica
Regra em uma linha: com did / didn't, o verbo volta a ser use to. Sem eles, é used to.

4. would — só ações, nunca estados

FraseCert?Por quê
We would meet every Friday.✔ação repetida no passado
My grandma would tell us stories.✔hábito que se repetia
"There would be a tree here."✘estado: não se repete
"I would have a bike."✘posse é estado
O teste: acontecia várias vezes? → would ou used to. Era sempre igual, sem repetição? → só used to. Em dúvida, used to sempre funciona.

5. be used to — o familiar de agora

FraseDepois de toSentido
I'm used to the new bus.substantivojá conheço, não estranho
She's used to getting up early.-ingo to é preposição
"I'm used to get up early."✘ infinitivoaqui o to não é infinitivo
É o nó da aula, e ele se desfaz ao nomear: o to de used to walk é marcador de verbo; o to de used to walking é preposição — e preposição pede substantivo ou -ing.

6. get used to — o processo

FormaExemploO que diz do tempo
be used toI'm used to it.já está pronto, ponto final
get used toI'm getting used to it.ainda em andamento
get used to (passado)I got used to it.o processo terminou
Be descreve o estado; get descreve o caminho até ele. A diferença é a mesma entre I'm tired e I'm getting tired.

7. Os três parecidos

FormaExemploSentido
used to + verboWe used to walk.hábito no passado
be used to + -ingI'm used to walking.familiaridade agora
use + objetoI use a pen.verbo comum: usar
Três ideias, três tempos: passado / agora / qualquer tempo. O d na terceira forma não existe porque é presente: use.
