# KIDS — SPINE (work file, PHASE 1)

One line per concept family, in teaching order. `Test-Roadmap.ps1 -Counts` counts these lines; the count is quoted in `## Decisions`.

- sound: letters vs sounds — lessons 1–2 — PEDAGOGY.md pins lesson 1 to the "vowels have no fixed sound" overview and lesson 2 to elaborating it; opaque + core, so it is the first structural rule and it makes every later reading guess cheap.
- cognates and their traps — lessons 1–2 — the other pinned pair; transparent + core (suffix codes) and partial + core (false friends), so the fastest wins and the biggest hidden trap arrive together.
- hooks: be / get / have / do / go — lessons 3–5 — transparent + core; `get` is taught as the wildcard and every later lesson leans on these five, so they come before any tense.
- articles and existence — lesson 5 — partial + core; a/the and there is/are are needed before the first description, and PT "tem" → there is is a partial transfer that misleads immediately.
- the [mode] skeleton — lessons 6–8 — opaque + core: one rule (marker on the mode, verb back to base) reused at every tense, so it is placed early as a structural rule rather than later as "do-support".
- present simple = fact, not now — lessons 9–12 — the flagship PT contrast (partial + core); it can only be a meaning trap once the skeleton is in place.
- frequency and routine context — lesson 10 — transparent + core; always/usually/never sit inside the fact block they modify, and the routine register is the one the track lives in.
- continuous = right now — lessons 11–13 — partial + core; "estou estudando" maps to -ing only, so the contrast with the fact block is the whole point of the pairing.
- state verbs — lesson 13 — opaque + common; they are the exception that keeps the continuous honest, so they follow it, not precede it.
- can and the modal slot — lesson 14 — transparent + core; the modal slot is filled with something that never takes -s, which is the skeleton's first real test.
- prepositions by meaning — lessons 15–17 — partial + core: PT "para" splits into TO and FOR, so TO/FOR comes first, then the ON/IN/AT meanings, then verb + preposition units built on them.
- past of be and past simple — lessons 18–21 — transparent + core for was/were, partial for -ed pronunciation, opaque for the irregular set; the order inside the family follows that axis.
- pronouns and possessives — lesson 22 — transparent + core; needed before any retelling of other people's actions, and cheap to place while the past is fresh.
- commands and let's — lesson 23 — transparent + core; the bare-verb slot is the same slot the skeleton exposes, so it is free here.
- quantity — lesson 24 — partial + core for some/any, transparent for much/many; it closes block 1 by recycling the food and money contexts of lessons 9–12.
- future modes: gonna / will / arrangement — lessons 26–28 — opaque + core, placed first in block 2 because PEDAGOGY.md says gonna is a mode and the track talks about plans constantly; it opens block 2 with the form the student hears most.
- phrasal verb families: get, look — lessons 29–30 — transparent + core when grouped by root, which is PEDAGOGY.md's own instruction; needs the hooks from lessons 3–5 and the prepositions from 15–17.
- speech reductions and linking — lesson 31 — partial + common; placed after the grammar it hides, so wanna/gotta/gonna are recognised as forms the student already knows, not as new words.
- the perfect — lessons 32–35 — partial + core and the second flagship PT contrast ("trabalho aqui há 5 anos"); form first, then duration, then experience, then since/for.
- comparison — lessons 36–37 — transparent + common; -er/-est are cheap wins after the perfect block, and they widen the carrier phrases.
- obligation and advice — lesson 38 — partial + core; don't have to vs mustn't is a meaning trap that needs have/do from lessons 3–4.
- conditionals — lesson 39 — opaque + common; the first conditional sits here because it needs both the present and the future modes, and the imaginary ones are held for the tail.
- relative clauses — lesson 40 — partial + common; who/that/where need the question words from lesson 8 before they can be reused as linkers.
- gerund and infinitive — lesson 41 — partial + core; the -ing/-to split is where the continuous and the infinitive marker finally meet.
- past habits and past continuous — lessons 42–43 — partial + common; used to and was + -ing both lean on the past block from 18–21 and set up the reporting in 44.
- reported speech — lesson 44 — opaque + common; it is last in block 2 because the backshift table needs every tense the course has taught.
- the street layer: text-speak and youth slang — lessons 11–37 — partial + core for a 14-year-old who lives in chat; the abbreviation code opens block 1, the politeness border lands with the commands in 23, and the slang map lands with the ranking in 37, so the register's own language is finished before the last exam instead of parked in the tail.
- tail: past perfect, imaginary conditionals, passive, tags, dead slang — lessons 46–50 — nothing later depends on any of it, so it sits after the last exam by definition.
