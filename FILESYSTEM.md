- `lessons-archive/` is **untracked and gitignored**: it holds the old pre-rewrite lesson pages and is deliberately withheld from lesson generation (owner instruction 2026-11-03). It must not be opened, read or used as a reference for content, structure or layout — a lesson's shape is imagined from `designs/lessonNN.design.md` + PEDAGOGY-MAP.md. `kids/` and `adult/` are **tracked** (from 2026-11-03) and are generated from their own designs; `build-lessons.mjs` skips a track whose folder is gitignored, so `lessons.json` only advertises committed pages. `style.css` is implementation only for the same reason.
- track folders are created by generating a lesson into them; a track enters the manifest once its folder holds committed pages (`node build-lessons.mjs`).
- A file that the current batch does not reference is assumed fully functional; only a verification step proves otherwise.
