If We Miss the Deadline

O que esta aula instala: as quatro formas da condition (condição) — zero, primeira, segunda e terceira — como um sistema só. A lei é uma: a oração do if recua um passo e o resultado recebe o operador. Presente → will (primeira: If we miss it, we'll lose the client); passado → would (segunda: If we had more time, we would fix it); passado perfeito → would have (terceira: If we had booked earlier, we would have saved money); presente → presente (zero: If you press this, it stops). E o detalhe que decide tudo: o passado da segunda não é tempo, é distância — if I had more time fala de agora. O past perfect aparece aqui pela primeira vez, só dentro da terceira. Você também leva o would educado (I'd like…, Would you mind…?) e o woulda / coulda / shoulda da aula 14 viram gramática.

1. Uma lei, quatro formas

A condição tem duas metades: o if-clause (a oração da condição) e o result (o resultado). O que muda entre as quatro formas é só o quanto o falante acredita que aquilo é real — e o inglês marca essa crença recuando o verbo um passo. Ouça ▶ as quatro.

Formaif-clauseResultadoQuando se usa
zeropresentepresenteverdade sempre: se você faz, acontece
1stpresentewill + verboreal, futuro possível
2ndpassadowould + verboirreal agora — imaginação, conselho
3rdhad + particípiowould have + particípioirreal no passado — regret (arrependimento)
O erro que a aula existe para matar: if + will. Depois de if o futuro nunca aparece — if it rains, nunca if it will rain. O will fica só na metade do resultado. E a consequence (consequência) é sempre a segunda metade: primeiro a condição, depois o que ela causa.

2. A reunião de decisão

Três pessoas, um projeto atrasado. Cada fala é uma condição — e cada uma usa uma forma diferente. Leia, ouça ▶ e classifique.

Rui: If we miss the deadline, we 'll lose the client. That is the real risk.

Ana: If we had two more people, we would finish by Friday.

Bia: If I were the client, I would ask for a discount.

Rui: If we had booked the room in June, we would have paid half.

Ana: And if the client says no, we don't lose the account — we renegotiate.

Bia: Would you mind calling them today? If you call before noon, they will still answer.

A. Qual forma é?

1."If we miss the deadline, we'll lose the client."
2."If we had two more people, we would finish by Friday."
3."If we had booked the room in June, we would have paid half."
4."If the client says no, we don't lose the account."

3. Zero e primeira: o que é real

As duas formas reais. A zero descreve uma lei do mundo (apertou, para); a primeira aposta num futuro possível. Nas duas, o if-clause fica no presente — sem will, sem would. Ouça ▶ e compare.

1stIf she signs today, we 'll start on Monday.se ela assinar hoje, começamos na segundaum plano que depende de um fato
A diferença entre as duas não é de tempo — é de generalidade. A zero vale para qualquer vez; a primeira vale para esta vez. E o will pode virar going to sem mudar a forma (aula 15): if she signs, we're going to start on Monday.

A. Real — qual verbo?

1.If it ____ tomorrow, we cancel the visit.
2.If you ____ the red button, the alarm starts.
3.If the payment ____ today, we ship tomorrow.
4.If we ____ the file now, they get it by five.

4. Segunda: a distância, não o tempo

Aqui está o pulo do gato. A segunda usa o passado, mas não fala do passado: ela cria distância entre o falante e o fato — porque o fato não é verdade agora. If I had a car = se eu tivesse um carro (não tenho). E o were aparece com I, he, she, it: if I were you, sempre. Ouça ▶.

FraseO que ela dizEm português
If I had more budget, I would hire two people.não tenho o orçamentose eu tivesse mais verba, contrataria
If I were you, I would call today.não sou você — é um conselhose eu fosse você, ligaria hoje
If we didn't have this client, we wouldn't need the extra room.temos o clientese não tivéssemos esse cliente…
What would you do if the answer were no?a resposta ainda não é nãoo que você faria se a resposta fosse não?
would é o operador do irreal (não é passado de will aqui). A negativa vai nele: wouldn't. E note que a pergunta inverte a ordem: What would you do if…? — a condição pode vir depois do resultado, sem mudar nada.

A. Irreal agora — complete

1.If I ____ the manager, I would change the process.
2.If we had the figures, we ____ decide today.
3.She ____ answer if she knew the price.
4.What ____ you say if the client asked for a discount?

5. Terceira: o passado que não foi

A terceira é o regret (arrependimento): fala de algo que já passou e não aconteceu. É aqui que o past perfect estreia — had + particípio — mas só dentro desta moldura. O resultado usa would have + particípio, que na fala é woulda (aula 14). Ouça ▶.

FraseNa falaEm português
If we had booked earlier, we would have saved money.woulda savedse tivéssemos reservado antes, teríamos economizado
If she had called, I would have waited.woulda waitedse ela tivesse ligado, eu teria esperado
If we hadn't missed the flight, we wouldn't have paid the fee.wouldn't havese não tivéssemos perdido o voo, não teríamos pago a taxa
I should have checked the contract.shoulda checkedeu devia ter conferido o contrato
A diferença entre a segunda e a terceira é só quando: a segunda lamenta agora (não tenho o orçamento); a terceira lamenta o que passou (não reservei). O past perfect não é um tempo novo a conjugar — nesta aula ele é um bloco fixo: had + particípio.

A. Irreal no passado — complete

1.If I ____ the e-mail, I would have answered.
2.If they had signed, we ____ on time.
3.She ____ the train if she had left earlier.
4.If we hadn't paid, they ____ the order.

6. would educado — o pedido com saída

O mesmo would, agora sem condição: é o operador que deixa a porta aberta para o outro recusar. I'd like… é o pedido educado de sempre; Would you mind + -ing…? é o pedido que não pressiona. Ouça ▶ e compare com o pedido direto.

DiretoEducadoEm português
Send me the file.Would you mind sending me the file?você poderia me mandar o arquivo?
I want a later slot.I'd like a later slot.eu gostaria de um horário mais tarde
Change the date.Could you change the date?você poderia mudar a data?
Call me back.I'd like you to call me back.eu gostaria que você me ligasse de volta
Would you mind pede o verbo em -ing (Would you mind sending), nunca no infinitivo. E I'd like pede to + verbo (I'd like to see) quando o sujeito é você, ou you to + verbo quando é o outro (I'd like you to call).

A. O pedido educado

Mande a proposta. (Would you mind…?)
Eu queria uma reunião na quinta. (I'd like…)
Você poderia esperar até as três? (Could…?)
Eu gostaria que você confirmasse o horário. (I'd like you…)
