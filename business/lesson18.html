BUSINESS BOOK 1 · LESSON 18

Conditionals 1 & 2 + Would

Abertura: Hoje você aprende os dois condicionais do dia a dia: o 1º (real: "if I have time, I'll call") e o 2º (hipotético: "if I had more time, I would help"). E usa would para pedir com educação.

Caderno: no computador, segure Ctrl e arraste o mouse sobre um trecho para marcá-lo em amarelo (Ctrl+clique apaga a marca). O realce mora em uma camada só dele: ele nunca interfere numa nota ou gravação. Sem Ctrl: selecione um trecho → ▶ ouve · ⏺ grava · 📝 anota. Frase sublinhada = tem gravação; frase azul = tem anotação; clique para abrir.

1. 1º condicional: if + presente, will

Para algo real e possível: if + presente na condição, will no resultado.

ExemploEm português
If I have time, I'll call you.Se eu tiver tempo, eu te ligo.
If it rains, we'll cancel.Se chover, nós cancelamos.
If she calls, tell her I'm busy.Se ela ligar, diga que estou ocupado.

2. 2º condicional: if + passado, would

Para algo hipotético / imaginário: if + passado na condição, would no resultado. Com "eu", use if I were.

ExemploEm português
If I had more time, I would help.Se eu tivesse mais tempo, eu ajudaria.
If I were you, I'd call him.Se eu fosse você, eu ligaria para ele.
If we left now, we'd be on time.Se saíssemos agora, chegaríamos a tempo.

3. would para pedir com educação

would deixa pedidos e ofertas mais educados: I would like…, Would you mind…?

ExemploEm português
I would like a coffee, please.Eu gostaria de um café, por favor.
Would you mind sending that again?Você se importaria de enviar isso de novo?
I'd appreciate it if you could help.Eu agradeceria se você pudesse ajudar.

4. Treino (pode consultar)

A. Complete com will ou would

If I have time, I call you.
If I had more time, I help.
If it rains, we cancel.
If I were you, I call him.

B. Traduza — escolha a correta

1.Se eu tiver tempo, eu te ligo.
2.Se eu tivesse mais tempo, eu ajudaria.
3.Se eu fosse você, eu ligaria para ele.
4.Eu gostaria de um café, por favor.

C. Ouça e escolha

1. 2. 3. 4.

D. Escreva suas traduções

Se eu tiver tempo, eu te ligo. / Se eu fosse você, eu ligaria para ele. →

E. Grave ⏺

"If I have time, I'll call you. If I were you, I'd call him."
