Conditionals Review + Wish

Abertura: Hoje você revisa os condicionais e aprende o 3º (arrependimento no passado) e wish/if only para desejos e arrependimentos.

Caderno: no computador, segure Ctrl e arraste o mouse sobre um trecho para marcá-lo em amarelo (Ctrl+clique apaga a marca). O realce mora em uma camada só dele: ele nunca interfere numa nota ou gravação. Sem Ctrl: selecione um trecho → ▶ ouve · ⏺ grava · 📝 anota. Frase sublinhada = tem gravação; frase azul = tem anotação; clique para abrir.

1. Zero & 1º (fatos e condições reais)

Zero: fato geral (if + present, present). 1º: futuro possível (if + present, will).

ExemploEm português
If it rains, the ground gets wet.Se chove, o chão fica molhado.
If I have time, I'll call you.Se eu tiver tempo, eu te ligo.

2. 2º & 3º (irreais)

2º: presente irreal (if + past, would). 3º: passado irreal (if + had + particípio, would have + particípio).

ExemploEm português
If I had more time, I would help.Se eu tivesse mais tempo, eu ajudaria.
If I had known, I would have called.Se eu soubesse, eu teria ligado.

3. wish / if only — desejos e arrependimentos

Use wish + past para o presente irreal e wish + had + particípio para arrependimento no passado. if only é a versão enfática.

ExemploEm português
I wish I had more time.Queria ter mais tempo.
If only I'd known.Se eu soubesse…
I wish I hadn't said that.Queria não ter dito aquilo.

4. Treino (pode consultar)

A. Complete com would ou would have

If I had more time, I help.

B. Complete com wish + passado

I wish I (have) more time.
If only I (know).
