I Used to Work in the Old Office

O que esta aula instala: três formas que parecem iguais e vivem em tempos diferentes. used to + verbo é o hábito do passado que acabou (I used to work nights), e também serve para estados (there used to be a shop here). would + verbo repete ações do passado (we would meet every Friday), nunca estados. E be used to + -ing / substantivo é a familiaridade de agora (I'm used to presenting in English), com get used to para o processo de se adaptar. A lei: olhe para o tempo antes de olhar para a palavra — passado que acabou, ou presente que já é normal. A negativa e a pergunta perdem o d: didn't use to, did you use to…? E o som encolhe: used to é /juːstə/ — a mesma lógica da aula 14.

1. used to — o passado que acabou

Uma forma só, dois empregos: hábito que se repetia e estado que existia. Os dois acabaram — e é isso que used to diz. Ouça ▶.

TipoExemploEm portuguêsO que diz agora
hábitoI used to work nights.eu trabalhava à noite (antes)não trabalho mais
hábitoWe used to meet every Friday.nos encontrávamos toda sextanão nos encontramos mais
estadoThere used to be a shop here.havia uma loja aquinão há mais
estadoShe used to have an assistant.ela tinha um assistentenão tem mais
used to não é passado de use: é uma forma fixa, sempre com verbo nu depois. E ele marca contraste — quem diz I used to work nights está dizendo, sem dizer, que hoje é diferente.

2.There used to be a printer here.

4.She used to sign everything.

2. Negativa e pergunta — sem o d

O d pertence ao passado, e o did já carrega o passado. Então ele sai: didn't use to, did you use to…? — escrito sem d, dito com o mesmo /juːstə/. Ouça ▶.

FraseFormaEm português
I didn't use to like the software.negativaeu não gostava do software (antes)
Did you use to work there?perguntavocê trabalhava lá?
We didn't use to have this rule.negativanão tínhamos essa regra
Escreve-se use to (sem d) depois de did / didn't, porque o passado já está no auxiliar. O som não muda: continua /juːstə/.

3. would — só ações repetidas

Para hábitos repetidos, o inglês também aceita would — mas só para ações. Com estados (ter, ser, haver) ele não funciona. Ouça ▶ o contraste.

FraseAceita?Por quê
We would meet every Friday.simação repetida
He would call at six every day.simação repetida
There would be a shop here.não — use used to beestado, não ação
She would have an assistant.não — use used to haveestado, não ação
O teste: dá para contar quantas vezes? Se sim, é ação e would serve. Se é uma condição contínua (ter, ser, haver, saber), só used to. E note que would aqui não é condicional: é hábito do passado, marcado pelo contexto.

4. be used to + -ing — a familiaridade de agora

Aqui o to é preposição, não infinitivo — por isso vem -ing ou substantivo. be used to é o estado; get used to é o processo. Ouça ▶.

FormaExemploEm português
be used to + -ingI'm used to presenting in English.estou acostumado a apresentar em inglês
be used to + substantivoShe's used to the noise.ela está acostumada com o barulho
get used to + -ingWe're getting used to working remotely.estamos nos acostumando a trabalhar remoto
negativaI'm not used to this system yet.ainda não estou acostumado
O erro clássico: I'm used to present. Como o to é preposição, pede -ing: I'm used to presenting. Se você consegue trocar por um substantivo (used to the noise), é esta estrutura; se não, é used to + verbo do passado.

5. Os três parecidos

Mesma raiz, três vidas. A coluna do meio é o que você ouve; a da direita, o que a frase quer dizer. Ouça ▶ os três na mesma voz.

FormaSomSentidoExemplo
used to + verbo/juːstə/hábito ou estado no passado, acabadoI used to work nights.
be used to + -ing/nome/juːst tu/familiaridade agoraI'm used to working nights.
use (verbo comum)/juːz/usar uma ferramentaI use this tool every day.
O som separa os dois primeiros: used to cola em /juːstə/; be used to mantém o tu do to antes de vogal ou de -ing. E o terceiro é o verbo normal, com o z sonoro.

A. Qual das três?

1.I ____ this software every day.
2.I ____ have a desktop — now I use a laptop.
3.I ____ the new system now.
4.She ____ working alone.

6. A mudança de escritório

A equipe mudou de prédio e de sistema no mesmo trimestre. Leia, ouça ▶ e marque se a fala é sobre antes ou sobre agora.

Rui: We used to have two floors. Now we have one.

Bia: I 'm still getting used to the new badge system.

Rui: We would meet in the kitchen every Friday. Nobody does that now.

Bia: I didn't use to like open offices. I do now.

Rui: Are you used to the commute yet?

Bia: Almost. It used to take twenty minutes; now it takes forty.

A. Antes ou agora?

1."We used to have two floors."
2."I'm still getting used to the new badge system."
3."I didn't use to like open offices."
4."Are you used to the commute yet?"
