Words You Already Read — and How to Say Them

As duas ideias do curso

O que muda hoje

1. A letra não diz o som. O a de name e o de want são a mesma letra, com sons diferentes. Em português a letra entrega o som; em inglês, a palavra.

2. O fim da palavra é um código. informação já é information. A sua caixa de entrada está cheia delas:

information · organization · communication · the report · my project · video · important

Cada palavra tem um ▶: toque antes de dizer. No fim há um quiz.

A letra não decide o som

Cinco palavras, uma letra

A letra é a mesma nas cinco. O som, não: toque no ▶.

name · water · want · have · day

O inglês escreve como se dizia há séculos: a boca mudou, a escrita ficou. Ler a letra é adivinhar; ouvir é saber.

Aprende-se palavra por palavra.

O fim da palavra é um código

O código

O corpo não muda; muda o fim, e a troca é fixa:

  • -ção → -tion
  • -dade → -ty
  • -vel → -ble
  • -ante, -ente → -ant, -ent

O inglês não escreve -cion; trocar o fim basta.

informacion

information

Cada fim abre uma família inteira de palavras: você não decora, monta com o corpo que já tem.

Quatro palavras pelo código

informação → information

organização → organization

comunicação → communication

importante → important

O código não é uma lei

Três palavras, três histórias

Nem toda palavra sai do código. Estas três você guarda pelo uso:

projeto → project

vídeo → video

relatório → report

project tem o corpo de projeto, e o fim é -ct.

video é a mesma palavra, sem acento.

report não sai de código nenhum: é mais curta que relatório.

As duas frases do e-mail

Aprenda a frase, não só a palavra:

my project → meu projeto

the report → o relatório

É assim numa mensagem ao cliente.
